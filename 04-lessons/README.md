# 04 · Lessons worth keeping

These are compact principles to revisit before asking an AI tool to change a codebase.

- [Context before code](context-before-code.md)
- [Evidence over confidence](evidence-over-confidence.md)
- [Treat model output as untrusted input](model-output-is-input.md)
- [Design for correction](design-for-correction.md)
- [Keep the human accountable](human-ownership.md)

The aim is not to slow every task down. It is to spend review effort where the consequences of a wrong answer are highest.
