# Lesson · Keep the human accountable

AI can help draft code, propose architecture, explain unfamiliar concepts, and generate test ideas. It cannot take responsibility away from the developer who ships the system.

## What the builder still owns

- Whether the problem is worth solving.
- Whether the architecture matches the constraints.
- Whether the code is secure and maintainable.
- Whether the tests represent real risks.
- Whether data is handled lawfully and respectfully.
- Whether the product communicates limitations honestly.
- Whether the deployed system is monitored and supported.

## A final review question

Could you explain the change, identify its failure modes, and safely modify it without asking the same model to explain every line? If not, you probably have more understanding work to do before shipping it.
