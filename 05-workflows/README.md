# 05 · Workflows that hold up

A workflow should make important decisions visible and keep changes reviewable.

## Core loops
- [AI-assisted feature loop](ai-assisted-feature-loop.md) — frame, plan, implement, verify, review.
- [Evidence-led debugging loop](debugging-loop.md) — reproduce, isolate, test, correct, record.
- [Project handoff](project-handoff.md) — preserve the minimum context needed for the next session.

These are adaptable patterns, not rigid ceremonies. Skip steps that genuinely add no value, but do not skip verification for high-impact changes.
