# Workflow · Project handoff

Use this when starting a new AI session, moving to another developer, or returning to a project after time away.

## Handoff note

- **Goal:** one or two sentences.
- **Current scope:** what is included and excluded.
- **Entry points:** the few files that explain the system.
- **Contracts:** important API and data shapes.
- **Decisions:** decision, reason, and alternatives rejected.
- **Current state:** implemented, tested, deployed, or still planned.
- **Known issues:** exact reproduction and status.
- **Verification:** commands run and results.
- **Next step:** one small action with a clear completion condition.

Do not include credentials, private user data, raw production records, or entire conversation transcripts.
