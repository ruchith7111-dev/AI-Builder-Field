# 06 · Prompts & working patterns

A prompt is an interface for specifying a task. The strongest prompts make context, boundaries, and verification explicit.

## How to adapt a prompt

Replace placeholders with real repository details. Remove instructions that do not apply. Keep the model's task narrow enough that the output can be reviewed.

Do not paste secrets, personal records, customer documents, or private production data into a model unless the data-handling rules explicitly permit it.
