# Prompt · Debug with evidence

    Help investigate this issue. Do not immediately rewrite the code.

    Expected behaviour:
    [What should happen?]

    Actual behaviour:
    [What happened?]

    Reproduction:
    [Exact steps and input.]

    Environment:
    [Runtime, version, provider/model, relevant configuration.]

    Evidence:
    [Error, logs, stack trace, request/response with secrets removed.]

    Please:
    1. Separate facts from assumptions.
    2. List the most plausible causes.
    3. Explain what evidence would support or reject each cause.
    4. Suggest the smallest diagnostic test first.
    5. Wait for my test result before proposing a code change.

    Do not claim a cause is confirmed until the reproduction supports it.
