## Context supplied

## Review checklist
- [ ] The change satisfies the stated acceptance criteria.
- [ ] Every changed file is relevant.
- [ ] No unrelated refactor slipped in.
- [ ] Types and validation are correct.
- [ ] Error paths are understandable.
- [ ] Permission checks are enforced by the application.
- [ ] External inputs and model outputs are treated as untrusted.
- [ ] Secrets and personal data are not exposed.
- [ ] Tests cover a normal case and meaningful failure cases.
- [ ] Documentation matches actual behaviour.
