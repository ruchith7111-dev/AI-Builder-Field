## A review habit

For any project, keep four statements separate:

1. **Intent:** what the product should do.
2. **Design:** how the system is supposed to do it.
3. **Implementation:** what the current code actually does.
4. **Evidence:** what tests or observations demonstrate.

The difference is not academic. It prevents a portfolio description from promising behaviour that the application does not yet provide.
